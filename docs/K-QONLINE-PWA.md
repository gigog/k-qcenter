# K-QOnline แบบแอปติดตั้งได้ (PWA)

K-QOnline ใช้รูปแบบ Progressive Web App (PWA) เพื่อให้ผู้รับบริการติดตั้งจากหน้า HTTPS ลงบนหน้าจอหลักของ Android, iPhone และ iPad ได้ โดยยังใช้ K-QCENTER API เป็นแหล่งข้อมูล Slot, Capacity, Booking และสถานะคิวเพียงแห่งเดียว

## ขอบเขต

- เปิดจากไอคอนบนหน้าจอหลักในโหมดแอปแบบเต็มหน้าจอ
- มีชื่อและไอคอน K-QOnline
- มีทางลัดสำหรับจองคิวและตรวจสอบคิว
- เก็บเฉพาะไฟล์หน้าจอไว้ใช้เมื่อสัญญาณขาดช่วง
- ไม่สร้าง Booking ไม่แก้ Capacity และไม่เปลี่ยนสถานะคิวแบบ Offline
- เมื่ออุปกรณ์ Offline ระบบแจ้งเตือนและปิดปุ่มยืนยันการจอง
- วันที่และเวลาในหน้าจอยังคงแสดงเป็นปฏิทินไทยและ Asia/Bangkok
- ฟอนต์หลักยังคงเป็น Sarabun

## การติดตั้ง

ระบบต้องเปิดผ่าน HTTPS และไฟล์ `manifest.webmanifest` กับ `sw.js` ต้องอยู่ภายใต้ URL เดียวกับ K-QOnline

### Android

1. เปิด K-QOnline ด้วย Chrome
2. กดปุ่ม **ติดตั้งแอป** ที่ส่วนหัวเมื่อเบราว์เซอร์อนุญาต หรือเลือก **ติดตั้งแอป** จากเมนู Chrome
3. เปิด K-QOnline จากไอคอนบนหน้าจอหลัก

### iPhone และ iPad

1. เปิด K-QOnline ด้วย Safari
2. กดปุ่ม **แชร์**
3. เลือก **เพิ่มไปยังหน้าจอโฮม**

Safari ไม่ส่งเหตุการณ์ติดตั้งแบบเดียวกับ Chrome จึงใช้เมนูแชร์ของระบบในการติดตั้ง

## ความปลอดภัยและข้อมูล Offline

Service worker เก็บเฉพาะ HTML, CSS, JavaScript, manifest และไอคอนของแอป ไม่เก็บคำขอ API ไว้ใน cache และไม่จัดคิวคำขอจองเพื่อส่งภายหลัง การออกแบบนี้ป้องกันการสร้างคิวจากข้อมูล Capacity ที่หมดอายุและรักษา idempotency/transaction ไว้ที่ K-QCENTER API

หน้า Admin, Counter, ฐานข้อมูล และบริการภายในไม่รวมอยู่ใน PWA สาธารณะ และต้องไม่เปิดผ่าน Tailscale Funnel

## การอัปเดต

เมื่อแก้ไฟล์หน้าจอที่อยู่ใน app shell ให้เปลี่ยนชื่อ cache ใน `dist/sw.js` เช่น `k-qonline-v1` เป็น `k-qonline-v2` แล้ว deploy ตามคู่มือ Ubuntu เพื่อให้อุปกรณ์ติดตั้งรับไฟล์ชุดใหม่
