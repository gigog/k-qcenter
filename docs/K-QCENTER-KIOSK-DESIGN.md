# การออกแบบหน้า K-QCENTER Kiosk

หน้า Kiosk เป็นจุดบริการตนเองภายในสถานที่ ใช้งานผ่านเครือข่ายส่วนตัวและเรียกข้อมูลผ่าน K-QCENTER API เท่านั้น ไม่เชื่อมต่อฐานข้อมูลโดยตรง

## เมนูหลัก

หน้าแรกใช้แนวคิด Identity First: แสดงภาพเคลื่อนไหวการเสียบบัตรประชาชนกลางจอ พร้อมข้อความ `เสียบบัตรประชาชนเพื่อเลือกบริการ` และมีทางเลือกด้านล่างสำหรับผู้ไม่มีบัตรประชาชนหรือผู้ต้องการค้นหาด้วยหมายเลขโทรศัพท์ จากนั้นจึงแสดงบริการที่เหมาะสมในขั้นถัดไป

1. **เช็กอินด้วย QR** สำหรับผู้จองผ่าน K-QOnline สแกน QR หรือกรอกรหัสยืนยัน แล้วสร้าง Queue Ticket
2. **รับคิว Walk-in** แสดงเฉพาะ Slot ของวันนี้ที่ยังมี Capacity เลือกบริการและกรอกข้อมูลที่จำเป็น
3. **ตรวจสอบสถานะคิว** สแกน QR หรือกรอกรหัสเพื่อเปิด Timeline แบบอ่านอย่างเดียว ไม่เปลี่ยนสถานะคิว

ผู้มีรายการจองออนไลน์สามารถค้นหาด้วยรหัสคิว หมายเลขโทรศัพท์ เลขบัตรประชาชน หรืออ่านบัตรผ่าน Smart Card Bridge ประจำเครื่อง เมื่อพบรายการ ระบบแสดงข้อมูลแบบปกปิดและให้ผู้ใช้กดยืนยันการมาถึงก่อนเช็กอิน หากไม่พบรายการสามารถไปเลือกบริการ Walk-in ต่อได้ ส่วน QR จากใบคิวหรือหน้าจอโทรศัพท์ใช้เมนูตรวจสอบสถานะโดยตรง

## หลักการหน้าจอ

- ออกแบบสำหรับจอสัมผัส ปุ่มหลักและพื้นที่กดมีขนาดใหญ่
- ใช้ฟอนต์ Sarabun และข้อความภาษาไทยที่อ่านง่าย
- แสดงวันแบบปฏิทิน พ.ศ. และเวลา Asia/Bangkok
- ส่วนหัวและส่วนช่วยเหลือตรึงอยู่กับที่ ส่วนเนื้อหาเลื่อนได้เมื่อจอมีพื้นที่ไม่พอ
- รองรับกล้องเว็บ เครื่องสแกน QR แบบ Keyboard Wedge และการกรอกรหัสด้วยแป้นบนจอ
- มีโหมดตัวอักษรใหญ่สำหรับการเข้าถึง
- หลังออกบัตรคิวจะแสดงเลขคิว เวลารอโดยประมาณ QR ติดตามสถานะ และคำสั่งพิมพ์

## ความปลอดภัยและความเป็นส่วนตัว

- ล้างชื่อ เบอร์โทร และ Token เมื่อกลับหน้าหลัก
- กลับหน้าหลักอัตโนมัติหลังไม่มีการใช้งาน 90 วินาที และหลังแสดงบัตรคิว 60 วินาที
- การสร้าง Walk-in ส่ง `idempotency_key` เพื่อป้องกันการแตะซ้ำหรือ retry แล้วสร้างคิวซ้ำ
- การสร้างคิวและตัด Capacity ทำใน Transaction ฝั่ง K-QCENTER
- หน้า Kiosk ไม่แสดงข้อมูลสุขภาพ HN หรือเลขบัตรประชาชน
- QR สถานะใช้ Opaque Token และการเปิดดูสถานะไม่ถือเป็นการเช็กอิน

## อุปกรณ์ที่แนะนำ

- จอสัมผัสแนวตั้งหรือแนวนอน ความละเอียดขั้นต่ำ 1280×720
- Chromium หรือ Edge โหมด Kiosk และ HTTPS
- เครื่องสแกน QR แบบ USB Keyboard Wedge เป็นอุปกรณ์หลัก กล้องเว็บเป็นทางเลือก
- เครื่องพิมพ์ความร้อนตั้งเป็นเครื่องพิมพ์เริ่มต้นของระบบปฏิบัติการ
- เครื่องอ่านบัตรต้องเชื่อมผ่าน Adapter ที่ได้รับอนุญาตในระยะถัดไป ห้าม Browser อ่านหรือเก็บข้อมูลบัตรเกินความจำเป็น

## Smart Card Bridge

Browser เรียก `POST http://127.0.0.1:17890/read` ไปยัง Bridge ที่ติดตั้งประจำเครื่อง Kiosk โดย Bridge รับเฉพาะ Origin ของ K-QCENTER, bind เฉพาะ loopback และคืนเฉพาะ `citizen_id`, ชื่อ และชื่อเครื่องอ่าน ห้ามส่งภาพบัตร ที่อยู่ ศาสนา หรือข้อมูลบนชิปส่วนที่ไม่เกี่ยวข้อง เซิร์ฟเวอร์เก็บเลขบัตรเป็น HMAC เท่านั้นใน `citizen_id_hash` โดยกุญแจอยู่ภายนอกฐานข้อมูล

ติดตั้ง Bridge บน Windows ด้วย `tools/install-smartcard-bridge.ps1` ระบบจะคัดลอกโปรแกรมไปยัง Local AppData และสร้าง Scheduled Task ชื่อ `K-QCENTER Smart Card Bridge` ให้เริ่มเมื่อผู้ใช้เข้าสู่ระบบ

Smart Card Bridge รุ่น 3 มี Local Print Adapter ที่ `POST /print` รับเฉพาะข้อมูลใบคิวจาก Origin ที่อนุญาต แล้วพิมพ์ผ่าน Windows `PrintDocument` และ `StandardPrintController` ไปยังเครื่องพิมพ์ Default โดยตรง จึงไม่เปิด Print Preview และไม่พึ่ง flag ของเบราว์เซอร์ หน้า Kiosk ต้องไม่ fallback ไปใช้ `window.print()` อัตโนมัติ หาก Bridge หรือเครื่องพิมพ์ไม่พร้อมให้แสดงข้อผิดพลาดและอนุญาตให้กดพิมพ์ซ้ำ ตัวติดตั้งยังสร้าง Shortcut `K-QCENTER Kiosk` ด้วย Edge Profile แยกสำหรับการใช้งานเต็มจอ ก่อนใช้งานให้ตั้งเครื่องพิมพ์ความร้อนเป็น Default และปิด `Let Windows manage my default printer`

สำหรับการใช้งานผ่าน Google Chrome ให้ติดตั้ง `K-QCENTER Print Agent` แยกจาก Smart Card Bridge ด้วย `tools/install-kq-print-agent.ps1` Agent ทำงานเบื้องหลังแบบไม่มีหน้าต่างที่ `127.0.0.1:17891` และเริ่มอัตโนมัติเมื่อ Login หน้า Kiosk ติดต่อเฉพาะ `/health` และ `/print` ของ Agent โดยยังคงใช้ Smart Card Bridge ที่พอร์ต `17890` สำหรับอ่านบัตรเท่านั้น

สามารถกำหนด URL จุด Kiosk ตอนติดตั้งได้ เช่น:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install-smartcard-bridge.ps1 -KioskUrl "https://web-lab.tail53909d.ts.net:8443/dist/kiosk.html?kiosk=ER"
```

หน้า Kiosk ตรวจสุขภาพ Bridge ทุก 30 วินาทีและมีปุ่ม `↻` สำหรับรีเฟรชการเชื่อมต่อ PC/SC ทันที นอกจากนี้ Scheduled Task `K-QCENTER Smart Card Watchdog` ตรวจพอร์ตทุก 1 นาทีและเริ่ม Bridge ใหม่อัตโนมัติเมื่อโปรเซสหยุดทำงาน

Scheduled Task ทั้งสองรายการเรียกผ่าน `wscript.exe` และสคริปต์ VBS แบบ windowless เพื่อไม่ให้หน้าต่าง CMD หรือ PowerShell แสดงหรือกระพริบระหว่างการเริ่มระบบและการกู้คืน

## URL ช่วงทดลอง

หน้า Kiosk อยู่ที่ `/dist/kiosk.html` ผ่าน Tailscale Serve และไม่ควรเปิดผ่าน Tailscale Funnel
