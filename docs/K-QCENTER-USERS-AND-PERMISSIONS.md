# ผู้ใช้และสิทธิ์ K-QCENTER

หน้าหลังบ้าน `ผู้ใช้และสิทธิ์` ใช้สร้างและแก้ไขบัญชี กำหนดบทบาท ขอบเขตข้อมูล เปิด–ปิดบัญชี และเปลี่ยนรหัสผ่าน โดยการแก้ไขทุกครั้งถูกบันทึกใน Audit Log

## บทบาท

| บทบาท | สิทธิ์หลัก |
|---|---|
| `admin` | จัดการระบบ ผู้ใช้ โครงสร้างบริการ Slot และข้อมูลทั้งหมด |
| `kiosk_admin` | จัดการ Kiosk Template ปุ่ม และเปลี่ยน Template หน้าเครื่อง |
| `kiosk_manager` | ยืนยันสิทธิ์เพื่อเปลี่ยน Template ที่หน้า Kiosk |
| `counter` | ดูและดำเนินการคิวภายในขอบเขตที่ได้รับมอบหมาย |
| `viewer` | ดูข้อมูลและรายงานภายในขอบเขต โดยไม่มีสิทธิ์แก้ไข |

## ขอบเขต

- `ALL` ทุกสาขาและแผนก
- `BRANCH` เฉพาะสาขาที่เลือก
- `DEPARTMENT` เฉพาะแผนกที่เลือก

API ของ Dashboard, สาขา, แผนก, บริการ, Slot และรายการจองจะกรองข้อมูลตามขอบเขตของ Session ฝั่งเซิร์ฟเวอร์ การซ่อนเมนูบนหน้าจอไม่ถือเป็นกลไกควบคุมสิทธิ์

## ข้อกำหนดด้านความปลอดภัย

- ชื่อผู้ใช้ยาว 3–40 ตัวอักษร ใช้ตัวอักษรอังกฤษ ตัวเลข จุด ขีดกลาง และขีดล่าง
- รหัสผ่านต้องมีอย่างน้อย 10 ตัวอักษรและจัดเก็บด้วย Password Hash
- การแก้ไขผู้ใช้ต้องเป็น `admin` และผ่าน CSRF validation
- ผู้ดูแลไม่สามารถปิดบัญชีหรือลดสิทธิ์บัญชีของตนเองขณะที่กำลังใช้งาน
- การแก้ไขบัญชีไม่ส่งค่า Password Hash กลับไปยัง Client
- บัญชีที่ถูกปิดจะไม่สามารถใช้ Session เดิมต่อได้
