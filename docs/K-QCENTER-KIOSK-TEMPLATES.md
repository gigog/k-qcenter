# การตั้งค่า Kiosk Template

K-QCENTER รองรับการสร้างหน้าจอ Kiosk แยกตามอาคารและจุดติดตั้ง เช่น Kiosk อาคาร ER โดยไม่ต้องสร้างหน้า HTML แยกเป็นรายเครื่อง

## โครงสร้าง

```text
อาคาร
└── Kiosk Template (จุดติดตั้ง)
    ├── เมนูหลัก
    │   └── เมนูย่อย
    └── ปุ่มปลายทาง → แผนก / บริการ → Slot ของ K-QCENTER
```

- `Kiosk Template` กำหนดรหัส ชื่อ อาคาร ตำแหน่งติดตั้ง และสถานะเปิดใช้งาน
- `ปุ่ม Kiosk` กำหนดเมนูหลักหรือเมนูย่อย ไอคอน ลำดับ แผนก บริการ และตารางเวลาแสดงแยกวันจันทร์–อาทิตย์
- ช่อง `ไอคอน / อักษรนำเลขคิว` ที่เป็นตัวอักษรหรือตัวเลขจะใช้เป็น Prefix ของคิว Walk-in เช่น `ER` ออกเป็น `ER-001` และนับแยกตาม Prefix ภายในแผนกของวันนั้น หากใช้สัญลักษณ์หรือ Emoji ระบบยังแสดงเป็นไอคอน แต่ใช้ Prefix สำรองของแผนกสำหรับเลขคิว
- ปุ่มที่ผูกบริการจะอ้างอิงแผนกของบริการนั้นอัตโนมัติ
- API จะแสดงเฉพาะแผนกและบริการที่เปิดใช้งานและอยู่ในอาคารเดียวกับ Template
- เวลาแสดงปุ่มประเมินด้วยเขตเวลา `Asia/Bangkok` กำหนดเวลาแยกแต่ละวัน และรองรับช่วงเวลาข้ามเที่ยงคืน
- การกำหนดเวลาเริ่มเท่ากับเวลาสิ้นสุดหมายถึงแสดงตลอดวันนั้น และต้องเลือกวันแสดงอย่างน้อยหนึ่งวัน

## วิธีตั้งค่าจุด Kiosk อาคาร ER

1. เข้าสู่ K-QCENTER หลังบ้าน แล้วเลือก `ตั้งค่า Kiosk`
2. กด `เพิ่มจุด Kiosk`
3. เลือกอาคาร ER กำหนดรหัส `ER` และเปิดใช้งาน
4. กด `จัดการปุ่ม` แล้วสร้างเมนูหลัก เช่น `อุบัติเหตุและฉุกเฉิน`
5. เพิ่มเมนูย่อยและเลือกแผนกหรือบริการที่ต้องการ
6. เปิดหน้าจอด้วย `kiosk.html?kiosk=ER`

## การเปลี่ยน Template จากหน้า Kiosk

ผู้ใช้ทั่วไปจะไม่เห็นรายการ Template โดยตรง ให้กด `ตั้งค่าจุด` ที่แถบด้านล่างและยืนยันชื่อผู้ใช้กับรหัสผ่านก่อน ระบบอนุญาตเฉพาะบทบาท `admin`, `kiosk_admin` และ `kiosk_manager` เมื่อยืนยันสำเร็จจึงจะแสดง Dropdown ของ Template ที่เปิดใช้งาน

เมื่อเลือกแล้ว เครื่องจะบันทึกรหัส Template ใน Local Storage และเปิดหน้า Kiosk ใหม่ด้วยพารามิเตอร์ `?kiosk=CODE` การยืนยันสิทธิ์เป็นแบบครั้งเดียวและไม่สร้าง Session บนเครื่อง Kiosk จึงไม่กระทบ Session ของหน้าหลังบ้าน

ตัวอย่าง URL บนระบบทดลอง:

```text
https://web-lab.tail53909d.ts.net:8443/dist/kiosk.html?kiosk=ER
```

## การทำงานหลังอ่านบัตร

1. Smart Card Bridge ส่งเฉพาะข้อมูลที่จำเป็นให้หน้า Kiosk
2. หน้า Kiosk เปิดเมนูหลักของ Template ที่ระบุใน URL
3. ผู้รับบริการเลือกเมนูหลักและเมนูย่อย
4. เมื่อเลือกปุ่มปลายทาง ระบบโหลดเฉพาะ Slot ของแผนก/บริการนั้น พร้อมช่วงลงทะเบียนที่ห้องบัตรและจำนวนรับรวมที่ยังเหลือ
5. ระบบไม่แสดง Slot ที่เต็มหรือสิ้นสุดช่วงลงทะเบียนแล้ว
6. การสร้างคิว Walk-in ยังทำผ่าน K-QCENTER API แบบ transactional และ idempotent

## กรณีรับบัตรก่อนเวลาให้บริการ

เวลาแสดงปุ่ม Kiosk แยกจากเวลาของ Slot ได้ เช่น NCD เปิดให้รับบัตรก่อน 07:00 น. แต่เริ่มให้บริการ 07:00 น.

1. กำหนดวันและเวลาแสดงของปุ่ม NCD เป็นช่วงก่อน 07:00 น. เช่น 05:00–07:00 น.
2. กำหนดตารางบริการของสาขาและแผนก NCD ให้เริ่ม 07:00 น. ในวันเดียวกัน
3. ตั้งแผนก NCD ให้มีระยะเวลา Slot 60 นาที
4. กำหนดจำนวนรับรวมต่อวันที่แผนก ระบบจะกระจายลงแต่ละ Slot และไม่คำนวณจากอัตรากำลัง

ก่อน 07:00 น. ผู้รับบริการจะเห็น Slot แรกเป็น `07:00–08:00 น.` และนำบัตรคิวไปยื่นที่จุดเวชระเบียนได้ เมื่อถึง 07:00 น. ปุ่มจะหยุดแสดงตามเวลาที่กำหนด โดยเวลาทั้งหมดประเมินด้วยเขตเวลา `Asia/Bangkok`

## ข้อควรระวัง

- ห้ามใช้รหัส Template ซ้ำ
- ไม่ควรผูกปุ่มกับแผนกคนละอาคาร เพราะ Public API จะไม่แสดงปุ่มนั้น
- การปิด Template, ปุ่ม, อาคาร, สาขา, แผนก หรือบริการ จะทำให้รายการนั้นไม่ปรากฏบน Kiosk
- หน้า Kiosk เป็น Public client แต่หน้าจัดการ Template ต้องผ่าน Session, CSRF และสิทธิ์ผู้ดูแลระบบ
